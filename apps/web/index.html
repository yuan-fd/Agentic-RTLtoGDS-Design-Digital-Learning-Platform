1
认识 Ibex 和 RTL

找到顶层模块、时钟端口和配置文件，知道每个文件在流程中负责什么。

2
跑综合和第一次 baseline

学习时钟约束、工艺平台和基本参数，运行一次完整的 RTL-to-GDS 基线。

3
看懂 GUI、日志和报告

4
改一个参数，再比较结果

用自然语言询问助手，改变利用率或时钟目标，比较两次真实运行的 QoR 证据。

Choose constraints and optimization goalThe Agent owns baseline settings, coupled-parameter search, repetition count, and stopping policy.

          
Optimization objective
This is not a manual parameter panel. The server owns an 11-dimensional mixed ORFS search space spanning floorplan, placement, CTS, and routing. It first measures the frozen default baseline, then covers at least 44 unique Sobol configurations before ARD-GP/qNEHVI may declare a three-round stall. Repeated OR_SEED runs estimate noise; they do not count as new design-space points. Clock and SDC requirements remain frozen.
