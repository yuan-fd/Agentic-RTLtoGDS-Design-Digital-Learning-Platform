# L1 S6 — tutorial-shaped bounded smoke

S6 proves the L1 control-plane sequence required by the supplied tutorial:

```text
natural-language request -> provider GoalDraft -> trusted GoalFinalizer
-> cited RUN_STAGE proposal -> S4 policy/trace/Runtime submit
-> real ProcessAdapter execution -> Runtime observation/reducer
-> cited QUERY_STAGE_METRICS -> evidence-cited stop reflection
```

The smoke uses a deterministic fixture adapter through the real
`WorkflowRuntime` and `ProcessAdapter`; it is an integration proof, not an
OpenROAD QoR claim.  It does not execute a model, a shell/Tcl generated by a
model, an optimizer, or an evaluator.  The fixture's registered report and
the Runtime/loop/trace SQLite databases are retained as raw smoke evidence.
The input knowledge, trusted-policy record and minimal RTL source are
version-controlled under `docs/evidence/l1_s6_tutorial_sources/`; every trace
pointer is computed from actual source bytes, never a placeholder digest.
